# Go 基础算法答题笔记 (Homework 01)

## 1. 只出现一次的数字 (Single Number)
- **重点考察方向**：Go 语言 `map` 的初始化与遍历、默认零值特性，以及位运算思维。
- **基础答题思路 (Map 法)**：
  - 使用 `make(map[int]int)` 初始化哈希表。
  - 遍历数组 `nums`，直接通过 `counts[n]++` 统计频率（利用了 Go 语言 map 不存在 key 时默认返回 0 的特性）。
  - 再次使用 `for k, v := range counts` 遍历 map，找到 `v == 1` 的键。
  - **空间复杂度**：O(N)
- **极致优化方向 (异或法)**：
  - 利用数学定理：`A ^ A = 0` 且 `0 ^ B = B`。
  - 只需要一个 `result` 变量，把数组里所有的数字互相异或，最后留下来的结果必定是那个“落单”的数字。
  - **空间复杂度**：O(1)，零内存分配，性能极致。

## 2. 回文数 (IsPalindrome)
- **重点考察方向**：防御性编程（卫语句拦截边缘情况）、类型转换陷阱、以及内存分配意识。
- **基础答题思路 (字符串双指针法)**：
  - **边界拦截**：开头连续使用多个无 `else` 的 `if` 拦截不可能的情况（如 `x < 0` 直接返回 false）。
  - **类型转换**：在 Go 中**绝不能**使用 `string(x)` 转数字，必须使用标准库 `strconv.Itoa(x)`。
  - **双指针对比**：定义 `l, r := 0, len(s)-1`，在 `for` 循环中向中间靠拢并对比 `s[l]` 和 `s[r]`。
  - **避坑**：右指针必须是 `len(s)-1`，否则会引发 `panic: index out of range`。
  - **空间复杂度**：O(N)，需要分配堆内存存储字符串，增加 GC 压力。
- **极致优化方向 (数学反转法)**：
  - 核心痛点是 `strconv.Itoa` 带来的堆内存分配（Heap Allocation）。
  - 可以不依赖字符串，利用 `% 10`（取最后一位）和 `/ 10`（砍掉最后一位）在循环里从右到左构建反转的数字。
  - 只需反转一半数字（防止溢出），对比前半部分和后半部分是否相等即可。
  - **空间复杂度**：O(1)，纯寄存器计算，零 GC 压力。

## 3. 有效的括号 (IsValid)
- **重点考察方向**：栈（Stack）数据结构在 Go 中的模拟、Hash Map 映射、以及边缘越界漏洞防范。
- **答题思路**：
  - **优雅匹配**：提前构建 `map[byte]byte` 存放右括号和左括号的映射，避免臃肿的 `if-else`。
  - **Go 语法避坑**：查询字典时必须用 `comma ok` 惯用法（`if m, ok := pairs[c]; ok`），不可用 `== nil` 判断基础类型 `byte`。
  - **模拟栈**：使用 `[]byte` 作为栈。左括号直接 `append` 入栈。右括号去对比出栈。
- **极致防御漏洞（Code Review 价值点）**：
  - 遇到右括号准备对比栈顶时，**必须提前判断栈是否为空 (`if len(stack) == 0`)**。如果直接 `stack[len(stack)-1]`，在应对极端流氓输入（如 `"]"` 或 `"(((())))))"`）时，会导致读取 `stack[-1]` 从而触发致命的 `panic` 越界崩溃。

## 4. 最长公共前缀 (Longest Common Prefix)
- **重点考察方向**：字符串的二维遍历思维、Go 语言切片特性的利用。
- **答题思路 (垂直扫描法)**：
  - 边界判断：`len(strs) == 0` 返回空。
  - **双循环纵向遍历**：以 `strs[0]` 为参照物。外层循环变量 `i` 遍历基准字符串字符，内层循环遍历其他字符串。一旦碰到长度不够 (`len(strs[j]) == i`) 或字符不匹配，触发截断。
- **底层性能亮点**：
  - 返回时使用切片语法 `return strs[0][:i]`。
  - 这种截取方式在 Go 底层是**零拷贝 (Zero-copy)** 的，没有 `malloc` 新字符串，只改变了切片的描述符（指向原数组的头部和长度 i），性能和内存利用率拉满。

## 5. 加一 (Plus One)
- **重点考察方向**：大整数的数组模拟、大端序（Big-endian）认知、原地修改（In-place）思维。
- **答题思路**：
  - **大端序认知**：既然 `[1,2,3]` 代表 123，最高位在最低地址，这就是典型的大端序。处理加法进位时，必然是从右向左逆向遍历（`for i := len-1; i >= 0; i--`）。
  - **极简原地修改**：如果不等于 9，直接加一返回（绝大部分情况）。如果等于 9，置为 0，让循环自然带入下一位（完美模拟进位）。
  - **极端扩容**：只有循环全跑完（意味着原数全是 9 变成了 000），才去 `make` 一块长度 `+1` 的新内存，并将首位置为 `1`。
- **避坑要点**：
  - **坚决避免 `[]int{}` 空切片越界赋值**。在 Go 中空切片长度为 0，不 `make` 就用下标 `[i]` 赋值必定引发 `index out of range` panic。

## 6. 删除有序数组中的重复项 (Remove Duplicates)
- **重点考察方向**：O(1) 空间复杂度的原地修改操作、经典的**“快慢双指针”**算法。
- **答题思路 (单循环双指针)**：
  - 定义慢指针 `i`，代表“已经排好的不重复大军的最后一名”。
  - 快指针 `j`（斥候）一路用 `for` 循环向右狂奔。
  - 只要斥候发现了和 `i` 不同的新元素（因为是有序数组，不同的必为新元素），就让 `i` 往前走一步，然后把新元素抄写到 `i` 的位置。最后返回 `i+1` 即可。
- **避坑要点**：
  - 千万不要用双层嵌套 `for` 循环去跳跃寻找！一旦遇到数组末尾全是连续相同字符时，外层循环无法正常步进，极其容易引发**死循环 (Infinite loop)**。
